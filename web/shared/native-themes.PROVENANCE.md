# Native herdr palettes

`native-themes.json` is generated by `node werdr/export-themes.mjs` from `src/app/state.rs` and the theme list in `src/config/theme.rs`.
Do not edit the generated JSON manually.
These palettes are derived from herdr's Apache-2.0-licensed source; the upstream license and notices in the repository apply.
The generator retains semantic terminal color names and reset values for the browser adapter to resolve.
Run `node werdr/export-themes.mjs --check` to verify that the browser data matches the checked-out native source.
